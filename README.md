# ComfyUI_MiniMaxH3_TotalMerger
ComfyUI node to merge MiniMax H3 models (INT8 ConvRot or bf16) by block groups, bake LoRAs, or just convert and save as bf16, INT8, W6A8 or W4A8 (with HQ variants). Live preview before saving.
